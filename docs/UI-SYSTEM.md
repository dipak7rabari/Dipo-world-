# DIPO WORLD — UI SYSTEM

## 1. UI Overview

DIPO WORLD uses a consistent, responsive, accessible, and reusable UI system across all products.

## 2. Design Principles

- Simple and clean interface
- Mobile-first responsive design
- Consistent spacing
- Clear typography
- Accessible controls
- Fast interactions
- Reusable components
- Consistent visual hierarchy

## 3. Layout

All pages should use a consistent layout structure:

**Header → Navigation → Main Content → Actions → Footer**

Layouts must adapt correctly to:

- Mobile
- Tablet
- Desktop

## 4. Components

Reusable UI components should be created for common elements such as:

- Buttons
- Inputs
- Forms
- Cards
- Modals
- Dropdowns
- Navigation
- Tabs
- Alerts
- Toasts
- Loading states
- Empty states
- Error states

## 5. Buttons

Buttons must clearly communicate their action.

Button types may include:

- Primary
- Secondary
- Outline
- Ghost
- Danger
- Icon

Buttons should include appropriate hover, focus, active, and disabled states.

## 6. Forms

Forms must provide:

- Clear labels
- Helpful placeholders
- Input validation
- Error messages
- Loading states
- Success feedback
- Accessible controls

Required fields must be clearly indicated.

## 7. Cards

Cards should be used to group related information.

Cards must maintain consistent:

- Padding
- Border radius
- Typography
- Spacing
- Actions

## 8. Navigation

Navigation must remain simple and predictable.

Users should always be able to understand:

- Where they are
- Where they can go
- How to return
- What action is currently selected

## 9. Feedback States

Every important action should provide appropriate feedback.

Supported states:

- Loading
- Success
- Error
- Warning
- Empty
- Disabled

## 10. Accessibility

UI components should follow accessibility best practices.

The interface should support:

- Keyboard navigation
- Screen readers
- Visible focus states
- Semantic HTML
- Accessible labels
- Sufficient color contrast
- Touch-friendly controls

## 11. Responsive Design

The UI must work correctly across different screen sizes.

No important content or functionality should be hidden or unusable on smaller screens.

## 12. UI Consistency

All DIPO WORLD products should follow the same core design principles while allowing product-specific interfaces when required.

**DIPO BIO** and **DIPO QR** should feel like products of the same DIPO WORLD ecosystem.

## 13. UI Development Rule

New components should be:

**Reusable → Responsive → Accessible → Tested → Production Ready**
