# QR Code Styling

QR Code Styling is used by DIPO WORLD for creating customizable
QR codes.

## Used For

- Styled QR codes
- Custom colors
- Custom gradients
- QR logos
- Frames
- Shapes
- Download/export
- SVG output
- Canvas output

## Integration

DIPO WORLD application logic should access QR functionality through:

`assets/js/dipo-qr/`

The library itself must remain isolated inside this directory.

Do not place page-specific logic or application state here.
