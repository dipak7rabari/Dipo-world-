# DIPO WORLD — Libraries

This directory contains third-party libraries used by DIPO WORLD.

## Libraries

### JsBarcode
Location:
`lib/jsbarcode/`

Purpose:
- Barcode generation
- Barcode rendering
- Barcode export support

### QR Code Styling
Location:
`lib/qr-code-styling/`

Purpose:
- QR code generation
- Styled QR codes
- Logo support
- Custom colors
- Custom frames
- Download/export support

## Important

Third-party library source files should remain isolated from
DIPO WORLD application code.

Do not place business logic, page logic, UI logic, or application
state inside this directory.

Application code belongs inside:

`assets/js/`
