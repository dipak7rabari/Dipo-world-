# JsBarcode

JsBarcode is used by DIPO WORLD for barcode generation.

## Used For

- Code 128
- EAN
- UPC
- ITF
- MSI
- Pharmacode
- Barcode previews
- Barcode export workflows

## Integration

DIPO WORLD application code should access barcode functionality
through the dedicated DIPO QR JavaScript modules.

Do not put DIPO WORLD business logic inside this directory.
